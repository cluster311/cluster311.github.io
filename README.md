# cluster311.com

Sitio de Cluster311. HTML y CSS planos, sin build, sin dependencias.
Mismo kit de diseño que tbrsoft.com, con otro color de acento.

- `/` castellano, `/en/` ingles. Cada pagina enlaza a su version en el
  otro idioma con `hreflang`.
- `css/base.css`: el unico archivo de estilos.

## Ver en local

```
python3 -m http.server 8002
```

y abrir http://localhost:8002/
