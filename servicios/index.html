Servicios

Todo lo que entregamos esta abierto para el cliente y bien documentado. Si mañana queres seguir con otro equipo, podes.

Desarrollo de software libre a medida

Sistemas de gestion, plataformas web, integraciones y herramientas internas. Python en el servidor, HTML plano cuando alcanza, PostgreSQL para los datos. Todo con licencia libre y en un repositorio que es tuyo.

Datos abiertos y portales de datos

Publicacion de portales de datos con CKAN (el más usado en todo el mundo). Limpieza, normalizacion, catalogos, extensiones personalizadas y APIs.

Interoperabilidad y APIs

Conectamos sistemas que no se hablan: APIs REST documentadas, importadores y exportadores en formatos estandar (CSV, JSON, XML o lo que necesites), sincronizacion con sistemas de terceros. Preferimos el estandar abierto al formato del proveedor, siempre.

Inteligencia artificial aplicada

Usamos MCP para crear agentes que respondan o hagan acciones sobre tus datos de manera segura.

Salida de proveedores

Si tu organizacion esta atada a un sistema que no la respeta, te ayudamos a salir: extraccion de datos, migracion a software libre y un plan para que no vuelva a pasar. Sin drama y sin apagar nada hasta que lo nuevo funcione.

Brazo tecnico para ONGs

Trabajamos con organizaciones que ayudan a otras a dejar de depender de empresas tecnologicas atascadas en modelos viejos. Ponemos el equipo tecnico; ustedes ponen la causa y el territorio.
